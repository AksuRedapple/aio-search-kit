# 开源前的脱敏清单（硬性）

- [ ] **真实查询不得入库**：journal 里有 200+ 条个人查询（含机器配置、私有工具名）→ 只放合成样例；
- [ ] **凭据路径与文件名**：`.credentials.yaml`、token 文件、key 一律不出现；
- [ ] **私有框架耦合**：插件依赖的私有包名/路径改为占位（`your-agent-framework`）；
- [ ] **内网地址/域名**：`192.168.*`、tailnet 域名、公司域一律替换；
- [ ] **个人身份**：不写公司与岗位；
- [ ] 跑一次 `grep -rEi "api[_-]?key|token|@|192\.168|\.local|\.internal"`，人工逐条判。
